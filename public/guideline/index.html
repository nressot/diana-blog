01 / Histoire de la marque

L'univers litteraire de Diana

Le Coven de Diana est un espace de creation litteraire ou la magie des mots rencontre les mysteres des etoiles. Un sanctuaire pour les ames en quete de sens, guidees par les constellations et les cycles lunaires.

Litterature

Un amour profond pour les mots, les histoires et la beaute de l'ecriture sous toutes ses formes.

Magie

L'enchantement des mots, les mysteres celestes et la magie des constellations qui guident nos chemins.

Mystere

L'attrait pour l'inconnu, les phases de la lune et les secrets caches entre les lignes.

Chaleur

L'accueil bienveillant d'une communaute passionnee, comme un foyer ou chacun trouve sa place.

02 / Logo Principal

Notre embleme

Le logo principal du Coven de Diana combine un livre ouvert symbolisant la litterature, entoure d'etoiles et de phases lunaires evoquant la magie et le mystere. Ce logo est utilise pour les grandes surfaces et supports ou le detail est apprecie.

Hierarchie des logos

Logo Principal: Utiliser pour les grandes surfaces (hero sections, affiches, couvertures de livres). Du fait de ses nombreux details, ce logo n'est pas adapte aux petites tailles.

Logo Simple: Utiliser pour les petits formats (header du site, favicon, reseaux sociaux en petit format). Voir la section "Logo Simple" ci-dessous.

Mode Clair (Light Mode)

Mode Sombre (Dark Mode)

Zone de protection

Toujours maintenir un espace minimum autour du logo egal a la hauteur de la lettre "D" de Diana pour garantir sa lisibilite.

X X X X

Taille minimale

Le logo principal necessite une taille minimale importante pour rester lisible. En dessous de ces dimensions, utiliser le Logo Simple.

Digital: 120px minimum

Print: 35mm minimum

02.5 / Logo Simple

Version simplifiee

Le logo simple est une version horizontale epuree, concue pour les petits formats ou le logo principal perdrait en lisibilite. Ideal pour le header du site, les favicons, et les avatars sur les reseaux sociaux.

Utiliser le Logo Simple pour:

  • Header / Navigation du site web
  • Favicon (icone navigateur)
  • Avatar reseaux sociaux (petit format)
  • Signature email
  • Tampons et cachets
  • Toute utilisation < 120px

Utiliser le Logo Principal pour:

  • Hero sections et bannieres
  • Couvertures de livres
  • Affiches et posters
  • Cartes de visite (logo principal)
  • Merchandise grand format
  • Toute utilisation > 120px

Versions du Logo Simple

Mode Clair (Light Mode) - Texte fonce

Mode Sombre (Dark Mode) - Texte clair

Support du Mode Sombre

Le site web supporte le mode sombre (dark mode). Les logos sont disponibles en deux versions:

Fond Clair

Utiliser les fichiers *-dark.svg (texte sombre)

Fond Sombre

Utiliser les fichiers *-light.svg (texte clair)
